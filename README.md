This is an unofficial crate for cloud-based drains for the slog logging
infrastructure in Rust.

## Usage

Add the following dependency into your Cargo.toml:

```
slog-cloud = "0.1"
```

See the `examples` directory and the [documentation](https://docs.rs/slog-cloud/) for usage examples.
